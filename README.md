# Železniční mapa ČR – webová verze 30

Webový balíček pro GitHub Pages. Obsahuje `index.html` a 16 regionálních HTML map. Každý region načítá data vložená do vlastního souboru; bez externích knihoven.

## Publikace
1. Vytvoř nový **veřejný** repozitář na GitHubu (např. `zeleznicni-mapa-cr`).
2. Nahraj **obsah této složky** do kořene repozitáře (soubor `index.html` musí být v kořeni).
3. V Settings → Pages nastav **Deploy from a branch**, `main`, `/ (root)` a ulož.
4. Otevři adresu GitHub Pages zobrazenou v nastavení.

## Omezení
- Verze 30 používá 16 samostatných regionálních stránek, **nejde ještě o automatické přepínání dlaždic při posunu**.
- Regionální hranice jsou pracovní a na hranicích oblastí může docházet k neúplnému zobrazení.
- Údaje nejsou určeny pro stavební vytyčování.
